# 环境依赖说明

## 1. 运行时

| 项 | 版本要求 | 说明 |
| --- | --- | --- |
| Python | 3.11+（建议 3.12） | 后端运行环境 |
| Node.js | 20 LTS+ | 前端构建 |
| npm | 10+ | 前端包管理 |
| Docker | 24+ | 本地启动中间件 |
| Docker Compose | v2 | 一键编排 |

## 2. 中间件

| 组件 | 版本 | 端口（默认） | 用途 |
| --- | --- | --- | --- |
| MySQL | 8.0 | 3306 | 业务库 + 应用库（本地可用 Docker 替代华为云 RDS） |
| Redis | 7.x | 6379 | 缓存、多轮上下文、限流、热门问题排行 |
| Qdrant | 1.9+ | 6333 / 6334 | 向量检索（四集合） |

## 3. 外部服务

| 服务 | 必需 | 说明 |
| --- | --- | --- |
| 华为云大模型 API | 是 | 通过统一适配层调用；需提供 endpoint、模型名、AK/SK 或 API Key |
| 华为云 RDS / DCS | 否 | 生产环境使用；本地开发用 Docker 版 MySQL / Redis |
| 华为云 ECS | 否 | 生产环境部署 Qdrant 与应用 |

## 4. 环境变量

复制 `project/.env.example` 为 `project/.env` 后填写。必需变量：

```dotenv
# 应用
APP_ENV=local
APP_PORT=8000

# 数据库
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_DATABASE=dataagent
MYSQL_USER=dataagent_ro
MYSQL_PASSWORD=<只读账号密码>
MYSQL_ADMIN_USER=root
MYSQL_ADMIN_PASSWORD=<初始化账号密码>

# Redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_DB=0

# Qdrant
QDRANT_URL=http://127.0.0.1:6333
QDRANT_COLLECTION_PREFIX=dataagent

# 大模型
LLM_ENDPOINT=<华为云大模型 API 地址>
LLM_MODEL=<模型名称>
LLM_API_KEY=<密钥>
```

**安全要求**：`.env` 不入库；只读账号与初始化账号分离；演示用密钥需限权并设置额度。

## 5. 硬件建议

- 本地演示：4 核 8 GB 内存，20 GB 空闲磁盘。
- 含向量库全量索引与百万行模拟数据时，建议 8 核 16 GB。
- 首次构建向量索引与导入数据耗时较长，属正常现象。

## 6. 一键安装

```bash
bash readme/install.sh
```

脚本会检查 Python / Node / Docker 版本，创建虚拟环境，安装前后端依赖，并拉起中间件容器。脚本不可用时按本文档手动安装，步骤见 `部署运行步骤.md`。

## 7. 常见环境问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 连接 MySQL 失败 | 容器未就绪或端口占用 | `docker compose ps` 查看状态，等待健康检查通过 |
| Qdrant 集合为空 | 未执行初始化脚本 | 执行建表 + 导入数据 + 索引重建流程 |
| 大模型调用 401 | 密钥或 endpoint 错误 | 核对 `.env`，确认模型名与区域 |
| Redis 不可用告警 | 未启动 | 可忽略，系统会自动降级为无缓存模式 |
| 前端请求 404 | 后端端口与代理配置不一致 | 检查 `VITE_API_BASE` 与后端端口 |
