## 评测怎么跑

- 全量评测（`--mode all`、`--repeat`）由用户手动跑，AI 编程助手不跑。每一步完成后，用户用它和基线对比。
- AI 编程助手做验证时，可以跑小规模评测：
  - 只在电商实例（8000 端口）上跑；
  - 每次只挑几道题，用 `--limit` 或 `--category` 限定，覆盖要验证的路径就够了，不跑全量，也不多次重复；
  - 改动文档里写明样本有多大，不把小样本的结果写成全量结论。
- 不在 DABench 实例（8001 端口）上跑评测。

## 依赖

- 计划 2、3 都依赖计划 1 的基线（第 1～3 步）。
- 2.4 依据中的"主要来源"：3.1 完成之前由模型自己写 SQL 计算，完成之后改用拆解工具。
- 1.7 依赖 2.4 输出的依据。
- DABench 的题怎么出、怎么判，见 `docs/DABench评测方案.md`。其中的评委模型、多次运行和并发运行，用计划 1 的 1.7、1.5 实现，不重复做。
