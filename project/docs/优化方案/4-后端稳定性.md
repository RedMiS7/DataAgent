## 4.1 外部服务重试和降级记录

**改法**
1. 重排、embedding 降级时，写入回答的 `degraded` 和 `warnings`；评测把降级次数作为过程指标统计。
2. 适配层对超时、429、5xx 最多重试 2 次，用指数退避，并受整体超时（`ask_timeout_seconds`、`analysis_timeout_seconds`）约束。
3. 查清 "Event loop is closed" 警告的来源，在请求结束时显式关闭异步客户端。

**涉及文件**
- `backend/app/rerank/dashscope.py`
- `backend/app/embedding/`
- `backend/app/agent/scope_model.py`
- `backend/app/agent/pipeline.py`

**测试**
- 模拟超时、429、5xx：按次数重试，超过整体时限就停止。
- 模拟重排失败：回答里带 `degraded` 和警告。
- 跑一次评测，日志里没有 "Event loop is closed"。

## 完成标准

| 项 | 标准 |
| --- | --- |
| 降级 | 每次降级都能在回答和评测结果里看到 |
| 重试 | 临时错误自动重试，不超过整体时限 |
| 日志 | 没有 "Event loop is closed" |
