# project/ —— 作品 Demo

可运行、可演示完整功能的工程代码目录。

## 目录规划

```
project/
├── backend/            # FastAPI 后端：问答主流程、SQL 校验、语义层
├── frontend/           # 对话页、结果表格、ECharts 图表、管理页
├── data/               # 模拟数据生成脚本与 8~10 张业务表
├── eval/               # 30~50 题评测集与评测脚本
├── docker-compose.yml  # 本地一键启动（MySQL / Redis / Qdrant / 应用）
└── .env.example        # 环境变量样例（不含任何真实密钥）
```

## 必须可演示的核心流程

1. 输入中文问题，例如“上个月哪个商品退货率最高？”
2. 展示时间解析与上下文改写结果。
3. 展示检索到的字段、指标口径、历史案例。
4. 生成并执行 SQL，返回结果表格。
5. 图表推荐与渲染（趋势类问题出折线图，排行为条形图）。
6. 一句话结论 + 口径说明 + 查看 SQL。
7. 多轮追问：“那上上个月呢？”沿用上文条件重新查询。
8. 异常归因：“退货率为什么涨了？”按商品 / 渠道 / 物流下钻。
9. 安全演示：危险 SQL 被拦截，敏感字段不可见。
10. 降级演示：停掉 Redis 或 Qdrant 后仍能完成问答。

## 提交要求

- [ ] `.env.example` 提供全部必需变量说明，不提交真实密钥
- [ ] 首次启动有数据初始化步骤（建表 + 导入模拟数据 + 建向量索引）
- [ ] 至少 1 个 demo 账号或免登录的本地演示模式
- [ ] 依赖锁定文件（`requirements.txt` / `package-lock.json`）
- [ ] 启动命令、端口、默认账号写入 `readme/部署运行步骤.md`
- [ ] 不提交 `node_modules/`、`venv/`、日志、数据库文件
