## 阅读顺序建议

1. 先读「环境依赖说明」，确认本机条件与外部账号。
2. 执行 `bash readme/install.sh`（或按文档手动安装）。
3. 按「部署运行步骤」启动，跑通一条示例提问。
4. 查看「开源组件说明」确认合规。
5. 「码道应用总结」用于评审了解 AI 参与度，截图证据见 `codearts_proof/`。
