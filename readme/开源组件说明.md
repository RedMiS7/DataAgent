## 合规检查清单

- [ ] 所有依赖版本与锁定文件一致

- [ ] 无未声明的商业 SDK 或闭源依赖
- [ ] 第三方字体、图标、图片均有明确授权记录
- [ ] 生成的 `THIRD_PARTY_NOTICES` 或本节表格随作品一并提交
- [ ] 无真实个人信息、真实订单数据进入仓库或演示素材
